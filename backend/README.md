# Бэкенд

API сервиса генерации документов: Laravel 13 + PhpWord.

Описание проекта, запуск и документация API - в [README в корне репозитория](../README.md).

## Полезные команды

Выполняются внутри контейнера:

```bash
docker compose exec app php artisan test
```

```bash
docker compose exec app php artisan migrate:fresh --seed
```
